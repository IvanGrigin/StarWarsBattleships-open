## 6. ⚠️ ВАЖНО: IP STAR WARS САМА ПО СЕБЕ

Замена ассетов закрывает только права на **файлы**. Названия «TIE», «X-wing»,
«Звезда Смерти», «Звёздные войны», узнаваемые силуэты и вселенная — ИП
Lucasfilm Ltd. Для публикации в Steam нужно одно из:

1. **Ребрендинг** (рекомендуется): свои названия кораблей («Имперский крейсер»,
   «Перехватчик серии T»), свои имена персонажей, обложка/стиль без SW-символики.
   Механика иRules остаются — они наши. Матрица замены: только тексты и названия;
2. Официальная лицензия Lucasfilm (нереалистично для инди);
3. Оставить как некоммерческий фан-проект вне Steam (текущий статус).
