# Лицензии арта v4 (карточки кораблей и персонажей)

**Вердикт проверки (все 102 файла):** все скачанные изображения — **non-free**
(официальный арт, кадры и промо-материалы Star Wars). Открытых лицензий
(PD / CC0 / CC-BY / CC-BY-SA / NC) среди них **нет**.

- Правообладатель: Lucasfilm Ltd. / Disney и/или авторы конкретных изображений.
- Источник: статьи Wookieepedia (starwars.fandom.com) — главные изображения статей,
  используемые вики по правилам fair use.
- **Разрешено:** использование в частном прототипе (файлы не публикуются наружу,
  источники записаны в `licenses.json` и `AUTHORS.md`).
- **Запрещено без разрешения:** публикация игры с этими файлами, продажа,
  размещение арта отдельно (сайт, сторов, соцсети).

## Как проверить конкретный файл вручную

У каждого файла в `licenses.json` есть поле `page` — ссылка на страницу файла
в Wookieepedia. На странице файла внизу указан шаблон лицензии:

- `{{Fairuse}}`, `{{Screenshot}}`, `{{Image from StarWars.com}}` → non-free;
- `{{CC-BY-SA}}`, `{{Self|CC-BY-SA...}}` → свободная CC-BY-SA (указать автора,
  наследовать лицензию; изменять можно);
- `{{CC-BY}}` → свободная CC-BY (указать автора; коммерческое использование можно);
- `{{PD}}` / `{{Self|PD}}` → общественное достояние (можно всё).

## План замены на публикуемый арт

1. Свободные картинки кораблей: Wikimedia Commons → категории «Star Wars
   ship models», «Star Wars LEGO» (фотографии моделей — часто CC-BY);
2. Персонажи: косплей-фото на Commons (CC-BY-SA) или собственные рисунки;
3. Каждый новый файл записывать в `licenses.json` с автором и лицензией.
