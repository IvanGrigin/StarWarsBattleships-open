# Размеченные примеры — спринт 1 (минимальный боевой контур)

Статус: справочный документ; два независимых читателя обязаны получать из каждого примера одинаковый результат (MASTER_PLAN_RU §19, M0). Числовые правила — `docs/rules/rules-v3.md`; порядок операций — `docs/rules/timing.md`; норматив для кода — `docs/contracts/core-api.md` §4–§7.

**Область действия.** Все примеры — только на базовом контуре спринта 1. Особые правила кораблей (перебросы, воскрешение, превращение, дальний выстрел) и способности героев **вне области**: они отключены (ADR-011) и реализуются параллельной задачей вне этого документа.

**Соглашения примеров.**

- Направления: `0` = N, `1` = NE, `2` = SE, `3` = S, `4` = SW, `5` = NW; дельты — core-api §1. Клетки axial `(q, r)`, поле радиуса 4: `max(|q|, |r|, |s|) ≤ 4`.
- Сектора по часовой стрелке от переда: индекс `0..5` = `F, FR, BR, B, BL, FL`; `sector_index = (dir_to_target - facing) mod 6`.
- Каждый индекс соответствует стороне гекса, а не вершине. Для соседей направление проходит через середину их общей стороны.
- `rng_index` в примерах локальный (0, 1, … внутри примера) для читаемости; в реальном матче счётчик сквозной от `MatchCreated`.
- Сила: `max(0, die + arc_modifiers[сектор])` — спринт-1 подмножество формулы core-api §4.4.
- Событие `DamageApplied` создаётся только при положительной разности сил; при ничьей урона нет и событие не создаётся. `hp_left` в событии не опускается ниже 0.
- `ship_instance_id` = `{seat}_{type_id}_{номер_в_сиде_с_нуля}`.
- Нелегальная команда не меняет состояние и не создаёт событий (core-api §5).
- Броски в примерах заданы явно («бросок атакующего 4») — конкретные значения зависят от seed и не моделируются здесь.

Числа карточек (arc, HP, щит) — `data/rulesets/v3/ships/*.json`, копия rules-v3 §10.

## Категория (а). Сектор для всех 6 направлений при фиксированном facing

Общая обстановка примеров 1–6: атакующий X-wing `A1_xwing_t65_0` в клетке `(0, 2)`, facing `0` (на север), `hp 4`, `щит 0`, `заряды 3`, атака не израсходована. Цель — TIE-истребитель `B1_tie_fighter_0`, `hp 4`, `щит 0`. Arc X-wing `[2,1,0,1,0,1]`, arc TIE `[2,1,0,0,0,1]`.

### Пример 1. Цель на севере (dir 0) → сектор F

- Состояние: X-wing `(0,2)` facing 0; TIE `(0,1)` facing 0.
- Сектор атакующего: `(0−0) mod 6 = 0` → **F** → `+2`. Направление от TIE к X-wing: дельта `(0,+1)` = dir 3 → сектор TIE `(3−0) mod 6 = 3` → **B** → `+0`.
- Броски: атакующий **4**, защищающийся **5**. Силы: `4+2=6` против `5+0=5`. Разность `1` → урон получает TIE.
- Итог: TIE `hp 4 → 3` (щита нет). X-wing не изменился; его атака израсходована.
- События: `AttackDeclared{attacker_id: A1_xwing_t65_0, target_id: B1_tie_fighter_0}`; `DieRolled{rng_index:0, sides:6, value:4, role:attacker}`; `DieRolled{rng_index:1, sides:6, value:5, role:defender}`; `StrengthCalculated{A1_xwing_t65_0, die:4, sector_index:0, arc_bonus:2, total:6}`; `StrengthCalculated{B1_tie_fighter_0, die:5, sector_index:3, arc_bonus:0, total:5}`; `DamageApplied{target_id: B1_tie_fighter_0, shield_damage:0, hull_damage:1, hp_left:3, shield_left:0}`.

### Пример 2. Цель на северо-востоке (dir 1) → сектор FR

- Состояние: X-wing `(0,2)` facing 0; TIE `(1,1)` facing 0.
- Сектор атакующего: `(1−0) mod 6 = 1` → **FR** → `+1`. От TIE к X-wing: дельта `(-1,+1)` = dir 4 → сектор `(4−0) mod 6 = 4` → **BL** → `+0`.
- Броски: **6** и **6**. Силы: `6+1=7` против `6+0=6`. Разность `1` → урон TIE.
- Итог: TIE `hp 4 → 3`.
- События: `AttackDeclared`; `DieRolled{0, 6, 6, attacker}`; `DieRolled{1, 6, 6, defender}`; `StrengthCalculated{X-wing, 6, 1, 1, 7}`; `StrengthCalculated{TIE, 6, 4, 0, 6}`; `DamageApplied{TIE, 0, 1, hp_left:3, shield_left:0}`.

### Пример 3. Цель на юго-востоке (dir 2) → сектор BR; побеждает защищающийся

- Состояние: X-wing `(0,2)` facing 0; TIE `(1,2)` facing 2 (на юго-восток).
- Сектор атакующего: `(2−0) mod 6 = 2` → **BR** → `+0`. От TIE к X-wing: дельта `(-1,0)` = dir 5 → сектор `(5−2) mod 6 = 3` → **B** → `+0`.
- Броски: **2** и **5**. Силы: `2+0=2` против `5+0=5`. Разность `3` → урон получает **атакующий**.
- Итог: X-wing `hp 4 → 1`. Урок: боковая атака против развернутого к тебе противника опасна.
- События: `AttackDeclared`; `DieRolled{0, 2, 2, attacker}`; `DieRolled{1, 5, 5, defender}`; `StrengthCalculated{X-wing, 2, 2, 0, 2}`; `StrengthCalculated{TIE, 5, 3, 0, 5}`; `DamageApplied{target_id: A1_xwing_t65_0, shield_damage:0, hull_damage:3, hp_left:1, shield_left:0}`.

### Пример 4. Цель на юге (dir 3) → сектор B; ничья

- Состояние: X-wing `(0,2)` facing 0; TIE `(0,3)` facing 0 (развернут к атакующему).
- Сектор атакующего: `(3−0) mod 6 = 3` → **B** → `+1`. От TIE к X-wing: дельта `(0,-1)` = dir 0 → сектор `(0−0) mod 6 = 0` → **F** → `+2`.
- Броски: **5** и **4**. Силы: `5+1=6` против `4+2=6`. Равенство → **урона нет**.
- Итог: `hp` и `щит` обеих сторон без изменений; `DamageApplied` не создаётся. Атака X-wing израсходована.
- События: `AttackDeclared`; `DieRolled{0, 5, 5, attacker}`; `DieRolled{1, 4, 4, defender}`; `StrengthCalculated{X-wing, 5, 3, 1, 6}`; `StrengthCalculated{TIE, 4, 0, 2, 6}`.

### Пример 5. Цель на юго-западе (dir 4) → сектор BL

- Состояние: X-wing `(0,2)` facing 0; TIE `(-1,3)` facing 4.
- Сектор атакующего: `(4−0) mod 6 = 4` → **BL** → `+0`. От TIE к X-wing: дельта `(+1,-1)` = dir 1 → сектор `(1−4) mod 6 = 3` → **B** → `+0`.
- Броски: **5** и **2**. Силы: `5+0=5` против `2+0=2`. Разность `3` → урон TIE.
- Итог: TIE `hp 4 → 1`.
- События: `AttackDeclared`; `DieRolled{0, 5, 5, attacker}`; `DieRolled{1, 2, 2, defender}`; `StrengthCalculated{X-wing, 5, 4, 0, 5}`; `StrengthCalculated{TIE, 2, 3, 0, 2}`; `DamageApplied{TIE, 0, 3, hp_left:1, shield_left:0}`.

### Пример 6. Цель на северо-западе (dir 5) → сектор FL; защищающийся развёрнут фронтом

- Состояние: X-wing `(0,2)` facing 0; TIE `(-1,2)` facing 2.
- Сектор атакующего: `(5−0) mod 6 = 5` → **FL** → `+1`. От TIE к X-wing: дельта `(+1,0)` = dir 2 → сектор `(2−2) mod 6 = 0` → **F** → `+2`.
- Броски: **3** и **4**. Силы: `3+1=4` против `4+2=6`. Разность `2` → урон атакующему.
- Итог: X-wing `hp 4 → 2`.
- События: `AttackDeclared`; `DieRolled{0, 3, 3, attacker}`; `DieRolled{1, 4, 4, defender}`; `StrengthCalculated{X-wing, 3, 5, 1, 4}`; `StrengthCalculated{TIE, 4, 0, 2, 6}`; `DamageApplied{target_id: A1_xwing_t65_0, shield_damage:0, hull_damage:2, hp_left:2, shield_left:0}`.

Сводка по facing `0`: dir 0 → F(индекс 0), dir 1 → FR(1), dir 2 → BR(2), dir 3 → B(3), dir 4 → BL(4), dir 5 → FL(5).

## Категория (б). Движение и повороты, расход зарядов, отказы

### Пример 7. MoveForward — успех

- Состояние: X-wing `A1_xwing_t65_0` в `(0,2)`, facing 0, `заряды 3`; клетка `(0,1)` свободна.
- Команда `MoveForward`. Проверки: `(0,1)` — сосед по facing (дельта `(0,-1)`), в поле, свободна; зарядов хватает.
- Расчёт: заряды `3 − 1 = 2`; клетка `(0,2) → (0,1)`; facing не меняется.
- Итог: X-wing в `(0,1)`, `заряды 2`, атака доступна.
- События: `ChargeSpent{ship_instance_id: A1_xwing_t65_0, reason:move, charges_left:2}`; `ShipMoved{ship_instance_id: A1_xwing_t65_0, from_q:0, from_r:2, to_q:0, to_r:1}`.

### Пример 8. RotateRight — успех

- Состояние: X-wing в `(0,2)`, facing 0, `заряды 3`.
- Команда `RotateRight`. Расчёт: `facing = (0+1) mod 6 = 1` (NE); заряды `3 − 1 = 2`; клетка не меняется.
- Итог: X-wing в `(0,2)`, facing 1, `заряды 2`.
- События: `ChargeSpent{A1_xwing_t65_0, reason:rotate, charges_left:2}`; `ShipRotated{ship_instance_id: A1_xwing_t65_0, from_facing:0, to_facing:1}`.

### Пример 9. Атака и движение в одной активации (свободный порядок)

- Состояние: X-wing `(0,2)` facing 0, `заряды 3`, атака не израсходована; TIE `(1,1)` facing 0 `hp 4`; клетка `(0,1)` свободна.
- Шаг 1, `DeclareAttack{B1_tie_fighter_0}`: цель — сосед (дельта `(+1,-1)`, dir 1). Сектор X-wing: FR → `+1`; сектор TIE: дельта `(-1,+1)` = dir 4 → `(4−0) mod 6 = 4` → BL → `+0`. Броски **4** и **4**: силы `4+1=5` против `4+0=4`, разность `1` → TIE `hp 4 → 3`. Атака израсходована, заряды не тронуты.
- Шаг 2, `MoveForward`: атака не блокирует движение. `(0,2) → (0,1)`, заряды `3 − 1 = 2`.
- Итог: X-wing в `(0,1)`, `заряды 2`, `attack_used`; TIE в `(1,1)`, `hp 3`.
- События: `AttackDeclared`; `DieRolled{0, 4, 4, attacker}`; `DieRolled{1, 4, 4, defender}`; `StrengthCalculated{X-wing, 4, 1, 1, 5}`; `StrengthCalculated{TIE, 4, 4, 0, 4}`; `DamageApplied{TIE, 0, 1, hp_left:3, shield_left:0}`; `ChargeSpent{X-wing, move, charges_left:2}`; `ShipMoved{X-wing, 0, 2 → 0, 1}`.

### Пример 10. MoveForward при 0 зарядов — отказ

- Состояние: X-wing в `(0,1)`, facing 0, `заряды 0`; `(0,0)` свободна.
- Команда `MoveForward` → отклонена: код ошибки `no_charges`. Состояние не изменилось, событий нет.
- Ответ ядра: `{"ok": false, "error": "no_charges"}`.

### Пример 11. MoveForward на занятую клетку — отказ

- Состояние: X-wing в `(0,2)`, facing 0, `заряды 3`; союзная Eta-2 Actis стоит в `(0,1)`.
- Команда `MoveForward` → целевая клетка `(0,1)` занята → отклонена: `occupied_cell`. Занятость проверяется против **любого** корабля, включая союзный. Состояние и заряды без изменений, событий нет.

### Пример 12. MoveForward за край поля — отказ

- Состояние: корабль в `(0,4)`, facing 3 (на юг), `заряды 2`.
- Команда `MoveForward` → целевая клетка `(0,5)`: `max(|0|, |5|, |-5|) = 5 > 4` — вне поля → отклонена: `out_of_board`. Событий нет.

### Пример 13. Поворот при 0 зарядов — отказ

- Состояние: X-wing в `(0,2)`, facing 0, `заряды 0`.
- Команда `RotateLeft` → отклонена: `no_charges`. Событий нет, состояние без изменений.

## Категория (в). Бой: исходы и урон

### Пример 14. Атакующий побеждает; щит поглощает часть урона

- Состояние: TIE Advanced X1 `A1_tie_advanced_x1_0` в `(2,-2)` facing 0 (`arc [3,1,1,0,1,1]`, `hp 6`, `щит 1`); Сокол тысячелетия `B1_millennium_falcon_0` в `(2,-3)` facing 0 (`arc [2,1,2,0,2,1]`, `hp 8`, `щит 1`).
- Сектор X1: дельта `(0,-1)` = dir 0 → **F** → `+3`. Сектор Сокола: дельта `(0,+1)` = dir 3 → `(3−0) mod 6 = 3` → **B** → `+0`.
- Броски: **5** и **3**. Силы: `5+3=8` против `3+0=3`. Разность `5`.
- Урон: щит Сокола поглощает `1` (`щит 1 → 0`), остаток `4` — корпус: `hp 8 → 4`.
- Итог: Сокол `hp 4`, `щит 0`. Оба живы.
- События: `AttackDeclared`; `DieRolled{0, 5, 5, attacker}`; `DieRolled{1, 3, 3, defender}`; `StrengthCalculated{X1, 5, 0, 3, 8}`; `StrengthCalculated{Falcon, 3, 3, 0, 3}`; `DamageApplied{target_id: B1_millennium_falcon_0, shield_damage:1, hull_damage:4, hp_left:4, shield_left:0}`.

### Пример 15. Защищающийся побеждает — урон получает атакующий

- Состояние: дроид-стервятник `A1_vulture_droid_0` в `(0,1)` facing 0 (`arc [1,1,1,0,1,1]`, `hp 4`, `щит 0`); звёздный разрушитель `B1_star_destroyer_0` в `(0,0)` facing 0 (`arc [2,2,1,1,1,2]`, `hp 8`, `щит 1`).
- Сектор стервятника: dir 0 → **F** → `+1`. Сектор разрушителя: дельта `(0,+1)` = dir 3 → **B** → `+1`.
- Броски: **1** и **4**. Силы: `1+1=2` против `4+1=5`. Разность `3` → урон атакующему.
- Итог: стервятник `hp 4 → 1` (щита нет); разрушитель не изменился.
- События: `AttackDeclared`; `DieRolled{0, 1, 1, attacker}`; `DieRolled{1, 4, 4, defender}`; `StrengthCalculated{Vulture, 1, 0, 1, 2}`; `StrengthCalculated{Destroyer, 4, 3, 1, 5}`; `DamageApplied{target_id: A1_vulture_droid_0, shield_damage:0, hull_damage:3, hp_left:1, shield_left:0}`.

### Пример 16. Ничья — 0 урона

- Состояние: Slave I `A1_slave_1_0` в `(1,-1)` facing 0 (`arc [3,1,0,2,0,1]`, `hp 6`, `щит 1`); Eta-2 Actis `B1_eta2_actis_0` в `(1,0)` facing 0 (`arc [2,1,1,0,1,1]`, `hp 5`, `щит 0`).
- Сектор Slave I: дельта `(0,+1)` = dir 3 → **B** → `+0`. Сектор Eta-2: дельта `(0,-1)` = dir 0 → **F** → `+2`.
- Броски: **4** и **2**. Силы: `4+0=4` против `2+2=4`. Равенство → урона нет.
- Итог: состояние кораблей не изменилось (кроме израсходованной атаки Slave I); `DamageApplied` не создаётся.
- События: `AttackDeclared`; `DieRolled{0, 4, 4, attacker}`; `DieRolled{1, 2, 2, defender}`; `StrengthCalculated{Slave1, 4, 3, 0, 4}`; `StrengthCalculated{Eta2, 2, 0, 2, 4}`.

### Пример 17. Пробитие щита насквозь

- Состояние: Призрак `A1_ghost_0` в `(1,-1)` facing 0 (`arc [2,1,0,2,0,1]`, `hp 6`, `щит 1`); TIE Advanced X1 `B1_tie_advanced_x1_0` в `(1,-2)` facing 0 (`arc [3,1,1,0,1,1]`, `hp 6`, `щит 1`).
- Сектор Призрака: dir 0 → **F** → `+2`. Сектор X1: дельта `(0,+1)` = dir 3 → **B** → `+0`.
- Броски: **6** и **2**. Силы: `6+2=8` против `2+0=2`. Разность `6`.
- Урон: `1` снимает щит X1 (`1 → 0`), остаток `5` — корпус: `hp 6 → 1`.
- Итог: X1 `hp 1`, `щит 0`.
- События: `AttackDeclared`; `DieRolled{0, 6, 6, attacker}`; `DieRolled{1, 2, 2, defender}`; `StrengthCalculated{Ghost, 6, 0, 2, 8}`; `StrengthCalculated{X1, 2, 3, 0, 2}`; `DamageApplied{target_id: B1_tie_advanced_x1_0, shield_damage:1, hull_damage:5, hp_left:1, shield_left:0}`.

### Пример 18. Уничтожение

- Состояние: Звезда Смерти `A1_death_star_1_0` в `(0,0)` facing 0 (`arc [7,0,0,-1,0,0]`, `hp 11`, `щит 2`); дроид-стервятник `B1_vulture_droid_0` в `(0,-1)` facing 0 (`arc [1,1,1,0,1,1]`, `hp 4`, `щит 0`). У обеих команд есть и другие живые корабли.
- Сектор Звезды Смерти: dir 0 → **F** → `+7`. Сектор стервятника: дельта `(0,+1)` = dir 3 → **B** → `+0`.
- Броски: **3** и **4**. Силы: `3+7=10` против `4+0=4`. Разность `6`.
- Урон: щита нет, корпус `6`: `hp 4 − 6 ≤ 0` → уничтожение.
- Итог: стервятник уничтожен и убран с доски (клетка `(0,-1)` освобождена); в спринте 1 уничтожение окончательно. Обе команды ещё имеют живые корабли — матч продолжается, `MatchEnded` нет.
- События: `AttackDeclared`; `DieRolled{0, 3, 3, attacker}`; `DieRolled{1, 4, 4, defender}`; `StrengthCalculated{DS, 3, 0, 7, 10}`; `StrengthCalculated{Vulture, 4, 3, 0, 4}`; `DamageApplied{target_id: B1_vulture_droid_0, shield_damage:0, hull_damage:6, hp_left:0, shield_left:0}`; `ShipDestroyed{ship_instance_id: B1_vulture_droid_0}`.

## Категория (г). Восстановление заряда при EndActivation

### Пример 19. Восстановление +1

- Состояние: X-wing `A1_xwing_t65_0` (активен), выполнил одно движение: `заряды 3 → 2`. Активация завершается.
- Команда `EndActivation`. Расчёт: восстановление `+1` (только по `EndActivation`): `2 + 1 = 3 ≤ 5`.
- Итог: `заряды 3`; флаг `activated` установлен; ход — следующему сиду по секции (е).
- События: `ActivationEnded{ship_instance_id: A1_xwing_t65_0, charges:3}` (заряды — после восстановления).

### Пример 20. Восстановление при максимуме — без изменений

- Состояние: Сокол `B1_millennium_falcon_0` (активен) не тратил зарядов: `заряды 5` (максимум).
- Команда `EndActivation`. Расчёт: `5 + 1 = 6`, ограничение максимумом: `заряды 5`.
- Итог: `заряды 5`.
- События: `ActivationEnded{B1_millennium_falcon_0, charges:5}`.

## Категория (д). Порядок ходов и пропуск сидов

### Пример 21. Обычный переход хода

- Состояние: `RoundStarted{round:1}` создан; `active_seat: A1`; ни один корабль ещё не активирован.
- Команды: `BeginActivation{A1_xwing_t65_0}` → `ActivationStarted{seat:A1, ship_instance_id:A1_xwing_t65_0, charges:3}`; затем без действий `EndActivation` → восстановление до `4`, `ActivationEnded{A1_xwing_t65_0, charges:4}`.
- Передача хода: следующий в цикле `A1 → B1 → A2 → B2` — `B1`, у него есть неактивированные живые корабли → `active_seat: B1`.
- Итог: `round 1`, `active_seat B1`; корабль A1 `activated: true`.
- События: `ActivationStarted{A1, A1_xwing_t65_0, charges:3}`; `ActivationEnded{A1_xwing_t65_0, charges:4}`.

### Пример 22. Пропуск сида без неактивированных живых кораблей

- Состояние: раунд 2; A1 активен и завершает активацию; у B1 остался один живой корабль, и он **уже активирован** в этом раунде; у A2 и B2 есть неактивированные живые корабли.
- Команда `EndActivation` (корабль A1).
- Передача хода: следующий в цикле — `B1`, но у него нет неактивированных живых кораблей → **пропуск** (без событий); следующий — `A2`, есть → `active_seat: A2`.
- Итог: `active_seat A2`; событий пропуска нет — следующий `ActivationStarted{seat:A2}` покажет пропуск задним числом.
- События: только `ActivationEnded{…}`. Если бы неактивированных живых кораблей не было ни у кого, вместо этого был бы `RoundStarted{round:3}`.

## Категория (е). Конец матча

### Пример 23. Победа по уничтожению

- Состояние: у команды B ровно один живой корабль — дроид-стервятник `B1_vulture_droid_0` в `(0,-1)` facing 0, `hp 1`, `щит 0`. Атакует Звезда Смерти `A1_death_star_1_0` в `(0,0)` facing 0, атака не израсходована. У команды A есть другие живые корабли.
- `DeclareAttack{B1_vulture_droid_0}`: цель — сосед (дельта `(0,-1)`). Сектор DS: **F** → `+7`; сектор стервятника: дельта `(0,+1)` = dir 3 → **B** → `+0`.
- Броски: **2** и **1**. Силы: `2+7=9` против `1+0=1`. Разность `8`: `hp 1 − 8 ≤ 0` → уничтожение.
- Проверка конца матча: у команды B не осталось живых кораблей → матч завершён.
- Итог: фаза `ended`, победитель — команда A.
- События: `AttackDeclared`; `DieRolled{0, 2, 2, attacker}`; `DieRolled{1, 1, 1, defender}`; `StrengthCalculated{DS, 2, 0, 7, 9}`; `StrengthCalculated{Vulture, 1, 3, 0, 1}`; `DamageApplied{B1_vulture_droid_0, 0, 8, hp_left:0, shield_left:0}`; `ShipDestroyed{B1_vulture_droid_0}`; `MatchEnded{winner:A, reason:elimination}`.

### Пример 24. Ничья по round_limit

- Состояние: `round_limit: 60`; раунд 60; B2 завершает последнюю неактивированную живую активацию раунда (все корабли всех сидов к этому моменту `activated: true`).
- Команда `EndActivation` → `ActivationEnded{…}`.
- Передача хода: неактивированных живых кораблей нет ни у кого; следующий раунд был бы `61`, но `61 > 60` → вместо `RoundStarted` матч завершается.
- Итог: фаза `ended`, победителя нет. Tie-breaker по HP в v3 не применяется.
- События: `ActivationEnded{…}`; `MatchEnded{winner:null, reason:round_limit}`.

## Категория (ж). Валидность драфта (бюджет 17, ≤1 группы 2, ≤2 одинаковых группы 1)

Ограничения на сид: 3 корабля; сумма стоимостей ≤ 17; ≤ 1 корабль группы 2; один тип группы 1 — не более 2; корабли группы 2 уникальны в матче; «Фантом» (`draftable: false`) в драфт не входит. Стоимость: TIE 4, X-wing 5, стервятник 5, Eta-2 6, Призрак 6, Звезда Смерти 6, TIE Adv X1 7, Slave I 7, Сокол 8, разрушитель 9.

### Пример 25. Валидный флот (граница бюджета, 1 корабль группы 2)

- Флот сида A1: TIE Advanced X1 (7, гр. 2) + дроид-стервятник (5, гр. 1) + X-wing (5, гр. 1).
- Проверки: сумма `7+5+5 = 17 ≤ 17`; группы 2 — `1 ≤ 1`; одинаковых типов гр. 1 — максимум 1 ≤ 2; все `draftable: true`.
- Итог: флот валиден. Каждое появление корабля фиксируется `ShipDrafted` (RNG потребляется только здесь — `rng.next_below` по отсортированному списку кандидатов):
  - `ShipDrafted{seat:A1, ship_instance_id:A1_tie_advanced_x1_0, ship_type_id:tie_advanced_x1, cost:7}`;
  - `ShipDrafted{seat:A1, ship_instance_id:A1_vulture_droid_1, ship_type_id:vulture_droid, cost:5}`;
  - `ShipDrafted{seat:A1, ship_instance_id:A1_xwing_t65_2, ship_type_id:xwing_t65, cost:5}`.

### Пример 26. Невалидный флот: два корабля группы 2 и перерасход бюджета

- Флот сида B1: Сокол тысячелетия (8, гр. 2) + Звезда Смерти (6, гр. 2) + TIE-истребитель (4).
- Проверки: сумма `8+6+4 = 18 > 17` — нарушение бюджета; кораблей группы 2 — `2 > 1` — нарушение лимита группы 2.
- Итог: флот невалиден по двум причинам; в алгоритме драфта такие кандидаты отфильтровываются до броска RNG (правило «кандидаты удовлетворяют всем ограничениям»). Дополнительно: второй Сокол у другого сида тоже был бы отклонён — корабли группы 2 уникальны в матче.

### Пример 27. Невалидный флот: три одинаковых типа группы 1

- Флот сида A2: три TIE-истребителя (4 × 3 = 12).
- Проверки: сумма `12 ≤ 17`; группы 2 — `0 ≤ 1`; но одинаковых типов гр. 1 — `3 > 2`.
- Итог: флот невалиден; третий TIE-истребитель того же типа недопустим одному сиду (другому сиду те же 2 TIE — можно: лимит действует на сид).
