# ЗВЁЗДНЫЕ ВОЙНЫ: БОИ ЗВЁЗДНЫХ КОРАБЛЕЙ — полные правила

*Версия правил v3.5 (соответствует движку ruleset v3_5)*

---

## 1. ОБЗОР

Два игрока — командующие флотами Звёздных войн — сражаются на гексагональном
поле открытого космоса. Побеждает командир, уничтоживший весь флот противника.

Каждый корабль уникален: у него своя живучесть, щит, сила дуг по шести
направлениям и особая способность. Побеждает не тот, у кого больше пушек,
а тот, кто подставляет врагу свой сильный борт и подставляет ему слабый.

## 2. ПОЛЕ

- Поле — **37 гексов** (шестиугольников) радиусом 3: центральный гекс и
  3 кольца вокруг него.
- Соседними считаются **6 гексов** по сторонам шестиугольника.
- Расстояние — число шагов между гексами (центральный гекс = шаг 0,
  первое кольцо = 1, второе = 2, третье = 3). Всё поле вмещает максимум
  3 шага от центра до края.

## 3. КОРАБЛИ

У каждого корабля есть параметры:

| Параметр | Значение |
|---|---|
| **КОРПУС (HP)** | сколько попаданий выдерживает. Когда корпус = 0 — корабль уничтожен |
| **ЩИТ** | поглощает урон до корпуса; **не восстанавливается до конца матча** — береги его |
| **ЭНЕРГИЯ (заряды)** | тратится на движение и повороты |
| **СИЛА ДУГ [6]** | шесть чисел на шести **сторонах** гекса корабля: 0 = носовая сторона, далее по часовой. Числа не относятся к вершинам. Отрицательное значение = мёртвая зона (минус к броску) |
| **СПОСОБНОСТИ** | уникальные эффекты (см. раздел 8) |

Пример записи: T-65 X-wing — Корпус 4, Щит 0, Энергия 5, Дуги [2, 1, 0, 1, 0, 1].

## 4. ФЛОТ И РАЗЫГРЫШ

- Стандартный матч — **дуэль 3×3**: у каждого игрока 3 корабля.
- При наборе флотов у каждого игрока **бюджет 17 очков**, не более **1 Heavy-корабля**
  (группа 2) и не более **2 одинаковых** лёгких (группа 1).
- Игроки по очереди выбирают по одному кораблю, пока у обоих не будет по 3.
- Корабли выставляются в своей стартовой зоне носом к противнику:
  - флот A — гексы (0,3), (0,2), (1,2);
  - флот B — гексы (0,−3), (0,−2), (−1,−2).

**Стоимость кораблей (очки):** Истребитель СИД — 4, Дроид-стервятник — 5,
T-65 X-wing — 5, Eta-2 Actis — 6, TIE Advanced X1 — 7, Slave I — 7,
Звезда Смерти I — 6, Призрак — 6, Сокол тысячелетия — 8,
Имперский звёздный разрушитель — 9.

## 5. ХОД РАУНДА

Матч длится до **60 раундов** (при превышении — ничья).

Раунд состоит из **активаций**: игроки поочерёдно активируют по одному своему
кораблю (начинает игрок A), пока не активируют все корабли обоих флотов. Затем
раунд заканчивается и начинается следующий.

**Активация корабля** (всё в любом порядке):

1. **Движение и повороты** — тратишь ЭНЕРГИЮ:
   - полёт на 1 гекс в **любом из 6 направлений** — 1 заряд;
   - поворот на 1 грань (60°) — 1 заряд.
2. **Атака** — одна за активацию, зарядов не требует.
3. **Завершение активации** — корабль больше не действует в этом раунде.

**Перезарядка в конце раунда** (для каждого корабля):

- если корабль **не потратил ни одного заряда** за раунд — энергия
  восстанавливается **полностью (5)**: «двигатель на холостом ходу»;
- если тратил — восстанавливает **половину от максимума, округляя вверх (3)**.

> Тактика: если корабль в этом раунде не нужен — не трать его энергию,
> и в следующем он получит полный бак. Щит, в отличие от энергии,
> за раунд не восстанавливается — потерял, значит потерял до конца матча.

## 6. АТАКА

Корабль может атаковать **один раз за активацию**.

**Условия:**

- цель — вражеский корабль **на соседнем гексе**, то есть две клетки имеют общую сторону (атаки через клетку нет —
  единственное исключение: дальний выстрел Звезды Смерти);
- корабль за свою активацию ещё не атаковал.

**Порядок бросков:**

1. **Атакующий** бросает **2 кубика d6** и складывает их.
2. Находит общую сторону своей клетки и клетки цели. К сумме прибавляет число,
   написанное на этой **стороне** гекса атакующего.
3. **Защищающийся** бросает **1 кубик d6**, прибавляет **+1** и прибавляет
   число на своей стороне той же границы — той, которая обращена к атакующему.
4. Обе силы не могут быть меньше 0.
5. **Сравнение сил**: кто сложил больше — победил в размене.
   **УРОН = разница сил**, и его получает ПРОИГРАВШИЙ.
   При равенстве урона нет.

> **Важно:** сектор всегда совпадает с серединой одной из шести сторон клетки.
> Направление на вершину гекса сектором не считается. Если клетки касаются только
> угла, они не соседние и обычная атака между ними невозможна.

**Пример.** TIE атакует X-wing с борта.
- Атака: кубики 5 и 2 → 7, плюс дуга борта TIE (+1) = **8**.
- Защита: кубик 2, плюс 1, плюс дуга борта X-wing (+1) = **4**.
- X-wing проиграл размен: урон 8 − 4 = **4** → сначала сгорает щит,
  затем корпус.

**Пример.** TIE атакует X-wing с борта.
- Атака: кубики 5 и 2 → 7, плюс дуга борта TIE (+1) = **8**.
- Защита: кубик 2, плюс 1, плюс дуга борта X-wing (+1) = **4**.
- Урон: 8 − 4 = **4** → сначала сгорает щит, затем корпус.

## 7. УРОН И УНИЧТОЖЕНИЕ

- Урон сначала снимает **ЩИТ**, остаток — **КОРПУС**.
- Корпус = 0 → корабль **уничтожен** (срабатывают способности «при взрыве»).
- Уничтоженные корабли снимаются с поля.

## 8. СПОСОБНОСТИ КОРАБЛЕЙ

| Корабль | Корпус/Щит | Дуги [0..5] | Способность |
|---|---|---|---|
| **Истребитель СИД** (4 оч.) | 4 / 0 | [2, 1, 0, 0, 0, 1] | **Воскрешение**: при уничтожении с шансом ½ воскресает на месте с 1d4 корпуса (щит 0; одна попытка за жизнь корабля) |
| **Дроид-стервятник** (5 оч.) | 4 / 0 | [1, 1, 1, 0, 1, 1] | **Переброс**: после своего броска, если хотя бы один кубик = 1 — шанс ½ перебросить один из них; второй результат окончателен |
| **T-65 X-wing** (5 оч.) | 4 / 0 | [2, 1, 0, 1, 0, 1] | **Удачный выстрел**: при ничьей в размене — шанс ½ нанести 1 урон (если X-wing атаковал) |
| **Eta-2 Actis** (6 оч.) | 5 / 0 | [2, 1, 1, 0, 1, 1] | — |
| **TIE Advanced X1** (7 оч.) | 6 / 1 | [3, 1, 1, 0, 1, 1] | — |
| **Slave I** (7 оч.) | 6 / 1 | [3, 1, 0, 2, 0, 1] | — |
| **Звезда Смерти I** (6 оч.) | 11 / 2 | [7, 0, 0, −1, 0, 0] | **Дальний выстрел**: единственный корабль, атакующий НЕ соседа — на любое расстояние, −2 к силе за каждую клетку сверх первой |
| **Призрак** (6 оч.) | 6 / 1 | [2, 1, 0, 2, 0, 1] | **Превращение**: при уничтожении на его месте появляется Фантом (полный корпус 2, щит 0, энергия сохраняется) |
| **Фантом** (нельзя брать в набор) | 2 / 0 | [2, 1, 0, −1, 0, 1] | — |
| **Сокол тысячелетия** (8 оч.) | 8 / 1 | [2, 1, 2, 0, 2, 1] | — |
| **Имперский звёздный разрушитель** (9 оч.) | 8 / 1 | [2, 2, 1, 1, 1, 2] | — |

*Читается так: [0]=нос, [1]=передний правый борт, [2]=правый борт,
[3]=корма, [4]=левый борт, [5]=передний левый борт.*

## 9. КОНЕЦ ИГРЫ

- **Победа**: все корабли противника уничтожены.
- **Ничья**: оба флота уничтожены одновременно, или истекли 60 раундов.

## 10. БЫСТРАЯ СПРАВКА (шпаргалка)

```
РАУНД = активации всех кораблей по очереди (A, B, A, B, A, B)
АКТИВАЦИЯ = движения/повороты за заряды + ОДНА атака
ПОЛЁТ = 1 заряд, любой из 6 гексов
ПОВОРОТ = 1 заряд, 60°
КОНЕЦ РАУНДА: не тратил энергию → 5 зарядов; тратил → 3 заряда; щит +1
АТАКА (≤3 гексов, 1 за активацию):
  атакующий: 2d6 + своя дуга к цели
  защищающийся: 1d6 + 1 + своя дуга к стрелку
  УРОН = разница (щит → корпус)
ПОБЕДА = уничтожить весь флот врага
```

## 11. УПРАВЛЕНИЕ В ДЕМО-ВЕРСИИ

- **ЛКМ по своему кораблю** — выбрать (затем кнопка «АКТИВИРОВАТЬ»);
- **ЛКМ по синей клетке** — полёт; **ЛКМ по красной цели** — атака;
- **курсовые стрелки у корабля** — поворот;
- **клик по любому кораблю** (в т.ч. чужому, даже на ходе бота) — разведка:
  характеристики и слабые сектора (карточка справа + янтарные цифры на гексе);
- **слайдер «УГОЛ»** — наклон камеры 10°…85°; **ПКМ** — облёт, **колесо** — зум;
- панель «БОЙ» показывает броски кубиков и расчёт урона;
- гекс-диаграмма в карточке: все шесть чисел стоят на сторонах гекса;
  зелёные числа — сильные дуги, красные — слабые.
