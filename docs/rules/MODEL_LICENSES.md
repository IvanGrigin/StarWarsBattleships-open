# Лицензии 3D-моделей (Minecraft-построек — источников мешей)

**Вердикт:** все скачанные постройки размещены на Planet Minecraft **без заявленной
лицензии** → по правилам сайта действует **«все права защищены у авторов»**.

- **Разрешено:** использование в частном прототипе (файлы не публикуются наружу).
- **Запрещено без разрешения автора:** публикация игры/мешей, продажа,
  размещение моделей отдельно.
- Исключение по заявлению автора: «Minecraft X-Wing design [FREE SCHEM]» —
  автор явно разрешил свободное использование схематика ( scope «free»,
  точные условия — уточнить у автора при публикации).

## План публикации

1. **Запросить разрешение** у каждого автора (шаблон ниже) — практика PMC:
   авторы обычно охотно дают разрешение с указанием авторства;
2. Либо **заменить** модели собственными постройками или свободными
   (Wikimedia Commons CC — фотографии моделей встречаются с CC-BY);
3. После разрешения — проставить лицензию в этой таблице и в игре
   (список авторов на титульном экране).
