# Имена коммитов AI-работников

Начиная с единой версии v0.4.1 каждый новый коммит AI-работника обязан иметь
тему и тело следующего вида:

```text
v0.4.1.00001/Codex: объединена базовая версия проекта

Время: 2026-09-23T12:30:00+02:00
Что: Перенесена история Claude, объединены изменения правил и интерфейса.
Почему: Нужна одна воспроизводимая точка старта для v0.5.
```

- `v0.4.1` — версия базовой линии; при следующем выпуске она меняется по
  решению владельца. Пять цифр после неё — порядковый номер коммита внутри
  этой версии, начиная с `00001`, без пропусков и повторов.
- После косой черты пишется исполнитель ровно как `Claude`, `GLM` или `Codex`.
  Имя показывает, кто подготовил и проверил коммит, а не автора Git.
- Тема после двоеточия кратко называет результат. В теле обязательны полные
  поля `Время`, `Что`, `Почему`. Время — ISO 8601 до секунд с часовым поясом.
  `Что` описывает конкретные изменения, `Почему` — причину или решение.
- Старые коммиты не переписываются: история до v0.4.1 сохранена дословно.
- Работа над интерфейсом v0.5.0 начата в `main`: первый коммит этой версии
  имеет номер `v0.5.0.00001/Codex`, затем счётчик растёт без пропусков.
- Работать следует от `main`. Временные рабочие копии не являются новыми
  авторитетными версиями; законченная работа сводится в `main`.

Локально включить проверку: `git config core.hooksPath .githooks`.
Проверка `commit-msg` отклоняет неправильный следующий номер и отсутствие
обязательных полей. CI проверяет все новые коммиты в push или pull request.
Обходить проверку AI-работникам нельзя.
