# ADR-007: Ориентация телефона — только landscape

Дата: 2026-09-13. Статус: принято.

## Контекст

3D-тактическое поле с камерой, HUD и журналом событий читаемо в горизонтальной ориентации; поддержка portrait в матче означает вторую раскладку UI и двойную работу.

## Решение

Матч на телефоне — только landscape. Поддерживаются обе landscape-ориентации (sensor landscape / обработка смены ориентации). Portrait во время матча показывает просьбу повернуть устройство, не перестраивая 3D-бой.

## Последствия

- UI проектируется landscape-first; safe area, вырезы и gesture-зоны учитываются с самого начала (MASTER_PLAN_RU.md §9.1).
- Меню/лобби могут использовать упрощённые layout-правила, но единый подход к ориентации фиксируется этим ADR.
- Тестовая матрица устройств обязана включать обе landscape-ориентации.
