# ADR-008: Правила информации — открытая информация, скрыт только будущий RNG

Дата: 2026-09-13. Статус: принято.

## Контекст

Исходная настольная игра полностью открыта: все корабли, заряды и броски видны всем. Детерминированная симуляция позволяет скрыть от наблюдателей ровно одну вещь — ещё не разыгранный поток случайных чисел.

## Решение

Вся информация матча открыта: состояние, журнал событий и статистика кубиков публичны. Скрыт только будущий RNG (последующие значения генератора). Наблюдения для ботов и ML строятся только из публичного состояния и не содержат future RNG или внутренних данных оппонента.

## Последствия

- Туман войны и скрытые сущности в v3 отсутствуют; их добавление = новый ADR и новый ruleset.
- Отсутствие скрытой информации упрощает сервер (нет per-seat secrets) и ML (наблюдение = публичное состояние).
- Семя матча и состояние RNG хранятся только на авторитетной стороне; клиент никогда не задаёт RNG (core-api, MASTER_PLAN_RU.md §18.1).
