# ADR-002: Движок — Godot 4.7

Дата: 2026-09-13. Статус: принято.

## Контекст

Нужен один движок, дающий: 3D-рендер на desktop и mobile, headless-режим для детерминированной симуляции и тестов, экспорт выделенного сервера, бесплатную лицензию для частного проекта.

## Решение

Godot 4.x stable, зафиксирован на версии **4.7**. Весь спринт 1 работает в режиме `--headless`; графический слой появляется не раньше M3.

## Последствия

- Язык проекта — GDScript (см. ADR-003); глобальный `rand()` движка запрещён — только собственный RNG (core-api §2).
- Обновления минорной версии Godot требуют прогона golden-тестов детерминизма.
- Node-модель Godot не должна проникать в ядро правил (`src/core/**` зависит только от базовых типов, core-api §0).
