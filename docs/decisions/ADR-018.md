# ADR-018: Энергия v3.5 — перезапись зарядов в конце раунда

Дата: 2026-09-14. Статус: принято (решение владельца: «энергия к концу раунда полностью перезаписывается; получается не +1, а половина с округлением в большую сторону; если в раунде ничего не делать — можно положить полную энергию»).

## Решения

1. **Отмена «+1 за активацию».** Правило v3.1–v3.4 «в конце активации корабль восстанавливает 1 заряд» удаляется. `charge_recovery_per_activation` удалён из данных; `EndActivation` больше не меняет заряды.
2. **Перезапись в конце раунда.** Когда раунд завершён (все живые корабли активированы), каждому ЖИВОМУ кораблю заряды не прибавляются, а ПЕРЕЗАПИСЫВАЮТСЯ:
   - если корабль за раунд НЕ потратил ни одного заряда → `charges = max_charges` (5) — «сберёг — заправился полностью»;
   - иначе → `charges = ceil(max_charges / 2)` (для максимума 5 — это 3).
   Параметры данных: `charge_round_reset: "half_up"`, `charge_full_if_unused: true` (`game.json`, ruleset v3_5).
3. **Счётчик трат.** У каждого корабля новое поле `spent_round` (int): увеличивается на стоимость каждого движения/поворота/иной траты заряда; сбрасывается в 0 при `RoundStarted`. Перезапись применяется один раз — в момент завершения раунда, до события `RoundStarted(n+1)`.
4. **События.** Новое: `ChargesRefreshed {ship_instance_id, charges, full}` — по одному на живой корабль в конце раунда (порядок — порядок массива ships). Смерть в раунде: мёртвые корабли не перезаписываются; воскрешённый (TIE) в следующем раунде перезаписывается на общих основаниях (его `spent_round` сохраняется с момента смерти). Превращение Ghost→Phantom: счётчик и заряды переходят (как в ADR-012/013 D2).
5. **Состояние.** `version: 4`; у корабля добавлено `spent_round: int`. `EndActivation` больше не излучает восстановления зарядов (поле `charges` в `ActivationEnded` сохраняется — фактическое количество на момент завершения).
6. **Начало матча.** Стартовые заряды 3 — совпадает со значением обычной перезаписи; раунд 1 начинается как «после сброса».

## Последствия

- Базовый темп: 3 заряда на раунд на корабль (раньше могло накапать 4–5 при бережной игре) — активации становятся компактнее.
- Появляется решение «сберечь раунд» (пропустить траты) → полные 5 зарядов на следующий раунд — форма темповой заготовки (рывок, серия поворотов+движений).
- Мины/бомбы, герои и бой не изменяются; меняется только ресурс ходов.

## Миграция

- ruleset_id → v3_5, ruleset_hash меняется; golden-replay и диф-корпус регенерируются. Старые реплеи несовместимы (ожидаемо).
- UI: журнал пишет «Заряды перезаписаны: X (полный — не тратил) / (⌈5/2⌉=3)»; панель — без изменений (квадратики зарядов уже есть).
