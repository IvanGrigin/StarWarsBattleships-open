# ADR-003: Язык основного кода — типизированный GDScript

Дата: 2026-09-13. Статус: принято.

## Контекст

Ядро должно быть единым для клиента, сервера и симуляций; возможное узкое место — горячий цикл симуляции при массовых прогонах. Python используется только для окружения обучения и эталонных генераторов, а не для правил.

## Решение

Весь игровой код — типизированный GDScript (аннотации типов обязательны). Перенос горячего симулятора в Rust (или иной компилируемый язык) рассматривается только после профилирования, доказавшего потребность, и оформляется отдельным ADR.

## Последствия

- В ядре запрещены `class_name` и глобальные имена: только `preload("res://...")` (core-api §0).
- Float запрещён в состоянии матча, событиях и командах — только целые числа (детерминизм).
- Для ML-тренировки ядро не портируется, а вызывается через адаптер/протокол (ADR-010).
