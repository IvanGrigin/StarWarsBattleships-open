# ADR-001: Лицензия и сеттинг

Дата: 2026-09-13. Статус: принято.

## Контекст

Игра использует сеттинг Star Wars (названия кораблей, персонажи, образы), права на который принадлежат Lucasfilm Ltd. / Disney. Проект — семейный прототип настольной игры, программная реализация создаётся без коммерческих целей. Публичный релиз пока не планируется, но решение нужно зафиксировать до начала работ (MASTER_PLAN_RU.md §18.3).

## Решение

Частный некоммерческий прототип в сеттинге Star Wars. Распространение, публикация и любое коммерческое использование запрещены. До любого публичного релиза решение пересматривается: либо получение необходимых прав, либо замена названий, персонажей, внешнего вида и lore на собственный IP.

## Последствия

- Требуемые права и ограничения ведутся в `LICENSES.md`.
- Для каждой Minecraft-постройки хранятся автор и разрешение; оригинальные текстуры Minecraft запрещены.
- Ребрендинг на собственный IP не заложен в архитектуру ядра: правила оперируют обезличенными id (`data/rulesets/v3/`), поэтому замена сеттинга затронет только данные карточек и ассеты.
