# ADR-004: Рендерер — Mobile как базовый профиль

Дата: 2026-09-13. Статус: принято.

## Контекст

Проект целится одновременно в desktop и mobile; риск — получить две разные игры, где desktop-картина недостижима на телефоне.

## Решение

Mobile-рендерер — основной профиль качества. Compatibility — fallback для слабых устройств. Forward+ — только desktop-enhancement, не требование правил и UI.

## Последствия

- Фичи, доступные только в Forward+, в базовой картинке не используются.
- `Desktop Low` обязан визуально соответствовать мобильному baseline (MASTER_PLAN_RU.md §9.2).
- Бюджеты кадров и памяти из §9.3 мастера-плана проверяются на мобильных профилях, а не только на desktop.
