# ADR-015: Поле v3.2 — радиус 3 (37 гексов), формат демо «3 против 3»

Дата: 2026-09-14. Статус: принято (решение владельца: «поле на 1 слой меньше, играть 3 против 3 корабля, в длину 7 по диаметру»).

## Решения

1. **Поле** — радиус 3, 37 гексов (было радиус 4 / 61). `board.json` обновлён; диаметр поля — 7 гексов.
2. **Формат демо** — дуэль «3 против 3»: команда A выставляет 3 корабля (сид A1), команда B — 3 (сид B1). Сценарий `classic_2v2.json` переведён на 2 сида с клиньями напротив: A1 [(0,3),(0,2),(1,2)] facing 0; B1 [(0,-3),(0,-2),(-1,-2)] facing 3. Бюджет и ограничения драфта — прежние (17 очков, ≤1 группы 2) на каждый сид.
3. **Схемы/валидатор** — seat_order допускает 2–4 сида (обязательны A1 и B1), board.schema закрепляет радиус 3.
4. **Полный формат 2×2** (4 сида × 3 корабля, 61 гекс) не отменяется: возвращается отдельным сценарием на M5 вместе с сетевой игрой; ядро уже читает состав сидов из сценария.

## Последствия

- Партии короче и плотнее: дистанция между фронтами 4 гекса вместо 5; доля решённых матчей у RandomLegal должна вырасти.
- Ценность секторов тыла выше — обходить негде, центр контролирует удар.
- Golden-replay, диф-корпус и отчёты баланса регенерируются (правила v3_2, новый ruleset_hash).
