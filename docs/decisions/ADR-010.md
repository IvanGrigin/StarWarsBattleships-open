# ADR-010: ML-интерфейс — PettingZoo AEC

Дата: 2026-09-13. Статус: принято.

## Контекст

Обучение нейросетей требует стандартной multi-agent среды с последовательными ходами четырёх агентов и командными наградами. Ядро при этом должно остаться единственным источником правил и не зависеть от Python.

## Решение

ML-интерфейс — адаптер PettingZoo AEC поверх того же детерминированного ядра (bindings или протокол). RLlib — опциональная надстройка, не зависимость ядра. Среда обязана проходить conformance-тесты PettingZoo.

## Последствия

- Python-сторона получает зависимость PettingZoo (версия, лицензия, назначение — в `docs/decisions/dependencies.md`).
- Фазы драфта, 4 сида, presence-маски и маски легальных действий входят в API среды (MASTER_PLAN_RU.md §14.1).
- Правила не дублируются в Python: адаптер только транслирует наблюдения/действия; рассинхрон ловится golden-corpus тестами.
