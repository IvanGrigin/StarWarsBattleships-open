# Ориентация 3D-моделей кораблей

Страница для просмотра всех скачанных моделей и исправления их ориентации —
по одной или группой до 9 штук сразу. Работает и с Мака, и с планшета.

## Запуск

```bash
python3 tools/model_preview/serve.py
```

Сервер печатает две ссылки: для этого Мака (`localhost`) и для планшета
(адрес Мака в локальной сети). Планшет должен быть в той же Wi-Fi-сети.
Раздаются только `tools/model_preview/` и `assets_source/external_models/` —
остальной репозиторий сервер не отдаёт.

## Номера моделей

У каждой модели постоянный номер — `#1`…`#211`. Он привязан к файлу и не
меняется ни при сортировке, ни после оценок; новые скачанные модели получают
следующие номера, номера удалённых не переиспользуются. Поэтому «поправь #37»
однозначно — на Маке, на планшете и через месяц. Номера хранятся в
`tools/model_preview/model_numbers.json`. Поиск по номеру: наберите `#37`.

## Порядок списка — от лучших к худшим

| Секция | Что в ней |
|---|---|
| 👍 без замечаний | лайк, ни комментария, ни пометок — годится как есть |
| 👍 с замечаниями | лайк, но есть комментарий или пометки; чем их больше, тем ниже |
| без оценки | ещё не смотрели |
| 👎 не годятся | дизлайк; тоже по числу пометок |
| файла нет на диске | записан в манифесте, но файл пропал |

Если у скачанной модели нет своей оценки, берётся оценка карточки каталога
Sketchfab, из которой она скачана (в списке помечено «(каталог)»). Своя оценка
всегда главнее. Список пересортировывается при открытии страницы, поиске и
смене вкладки — не на каждый клик, чтобы он не прыгал под пальцем.

## Правильная ориентация

У каждой модели нарисованы оси: **красная — нос**, **синяя — верх**, зелёная — правое крыло.
Корабль лежит правильно, когда нос смотрит по красной оси, а верх — по синей.

## Одна модель

Выберите модель в списке слева. Кнопки поворота на панели «Оценка модели»:

| Кнопка | Клавиша | Что делает |
|---|---|---|
| ⟲ 90° 🔴 | 1 | крен вокруг оси носа |
| ⟲ 90° 🔵 | 2 | разворот вокруг вертикали |
| ⟲ 90° 🟢 | 3 | тангаж вокруг оси крыльев |
| ⇄ нос 180° | 4 | развернуть нос назад |
| сброс | 0 | вернуть исходную ориентацию |

Shift + клавиша — поворот в обратную сторону.

## Группа до 9 моделей

1. Отметьте галочками до 9 моделей. Быстрее — через поиск: наберите `x-wing`
   и нажмите «Отметить найденные».
2. «Показать группу» — модели встанут сеткой 3×3, каждая в своей ячейке.
3. Кнопки поворота крутят **все корабли с синим кольцом** одновременно.
4. Тап по кораблю убирает кольцо — этот корабль в поворотах не участвует.
   «никого» снимает кольца со всех, дальше тапом включаете только нужных.

Типичный случай: из девяти скачанных моделей восемь стоят на хвосте —
открыли группу, сняли кольцо с единственной правильной, нажали 🟢 — готово.

## Где хранятся повороты

Каждый поворот сразу пишется на Мак в `tools/model_preview/model_reviews.json`
(строка «✓ сохранено на Маке» под заголовком). Там же оценки 👍/👎, пометки и
комментарии. Поворот — кватернион `[x, y, z, w]` в поле `orientation`.

Если сервер не запущен и страница открыта как файл, повороты остаются только в
памяти браузера — тогда нужна кнопка «Экспорт отзывов».

Запечь поворот в сам файл модели: `tools/model_preview/patch_glb_rotation.py --quat x,y,z,w файл.glb`.

## Облегчённые копии моделей

Часть скачанных моделей огромна: до 965 МБ, текстуры 8192 px (≈8 ГБ видеопамяти
после распаковки), до 4,9 млн треугольников и до 4062 отдельных мешей. Открытая
в браузере такая модель вешает и планшет, и Мак.

Поэтому страница по умолчанию показывает **облегчённую копию**: текстуры ≤512 px,
меши слиты, геометрия упрощена с допуском 0,2 % от габарита. На экране копию от
оригинала не отличить, а весят все 189 копий вместе ~0,2 ГБ против 6,8 ГБ
оригиналов. Поворот, выставленный на копии, в точности подходит к оригиналу.

Галочка **«оригинал (тяжело)»** в правом верхнем углу открывает полный файл —
для детальной проверки одной модели. В группе из 9 лучше не включать.

Копии собираются так (нужен Node.js; готовые пропускаются, пересобираются только
те, чей оригинал изменился):

```bash
python3 tools/model_preview/build_previews.py
```

Копии лежат в `raw_candidates/_preview/` и, как сами модели, в git не входят.
Итог последней сборки — в `tools/model_preview/previews_report.json`.

## Память и нагрузка

- В памяти видеокарты держится только то, что на экране: одна модель или одна
  группа. При переходе к другой модели предыдущая освобождается полностью —
  геометрия, материалы, текстуры, декодированные картинки и текстуры костей
  скелетных моделей. Листать можно сколько угодно, память не растёт.
- Файлы моделей браузер кэширует: повторное открытие не качает модель заново,
  а только сверяет, не изменилась ли она.
- Кадр рисуется только когда что-то изменилось: вращение камеры, поворот
  модели, загрузка, размер окна. Пока страница просто открыта, видеокарта
  отдыхает.
- Автоповорот означает непрерывную перерисовку, поэтому по умолчанию он
  выключен; включённая галочка запоминается в этом браузере.
- Проверить в консоли браузера: `__gpu()` — сколько геометрий, текстур и
  шейдеров сейчас в видеопамяти и сколько кадров нарисовано.

## Турнир: лучшая модель на каждый корабль игры

Каждая скачанная модель отнесена ровно к одному кораблю ростера игры
(`data/rulesets/v4/ships`, 50 типов) или к «нет в игре» — так одна модель
не попадёт в два типа. Разметку делает `classify_models.py` по названию модели
(и только если оно ничего не говорит — по группе, под которой она скачана):

```bash
python3 tools/model_preview/classify_models.py
```

Результат — `tools/model_preview/ship_classes.json`. Ручные правки со страницы
(`source: manual`) при повторном запуске не перезаписываются.

Вкладка **«Турнир»**:

1. Слева — все корабли игры: сколько моделей и статус (в процессе / не начато /
   выбрана лучшая / нет моделей в наборе).
2. Выбрали корабль — сверху эталонная картинка, на сцене две модели. Кнопки
   «◀ Левый лучше» / «Правый лучше ▶» или клавиши ← →. Backspace — отменить.
3. Победитель пары проходит в следующий круг, пока не останется одна модель.
   Сравнений — на одно меньше, чем моделей (6 моделей → 5 матчей), а не каждая
   с каждой. При нечётном числе лучшая по оценке модель проходит круг без игры.
4. Модель не того корабля — выберите ей верный тип или «нет в игре» в поле под
   кнопками: она уйдёт из этого турнира, сетка пересчитается сама.
5. Модели с 👎 в турнир не допускаются; порядок посева — как в списке «Скачанные».

Выборы и победители сохраняются на Мак в `tools/model_preview/tournament.json`
(`types.<корабль>.winner` — путь лучшей модели).

## Поиск и загрузка моделей для кораблей без моделей

```bash
python3 tools/model_preview/find_models.py      # поиск на Sketchfab (без токена)
python3 tools/model_preview/fetch_models.py     # загрузка того, что есть в Objaverse (без токена)
SKETCHFAB_TOKEN=<ваш токен> python3 tools/download_selected_models.py --all-v4   # остальное — с токеном
python3 tools/model_preview/build_previews.py   # облегчённые копии новых моделей
python3 tools/model_preview/classify_models.py  # разложить новые модели по кораблям
```

- `find_models.py` ищет только **скачиваемые** модели с лицензией Creative Commons и
  проверяет название по ключевым словам корабля (и словам-исключениям: LAAT не
  попадёт в пиратов). Итог — `missing_models_report.json` (автор, лицензия,
  ссылка) и новые запросы `v4:<корабль>` во вкладке «Каталог Sketchfab».
- `fetch_models.py` берёт модели из Objaverse — открытого датасета allenai на
  HuggingFace, где лежат CC-модели Sketchfab, собранные в 2022 году. Токен не нужен.
- Остальное скачивает официальный загрузчик Sketchfab. Токен — ваш личный:
  https://sketchfab.com/settings/password → «API token»; задаётся только в вашем
  терминале. `--all-v4` берёт всех найденных кандидатов без лайка по каждому,
  дизлайкнутые в каталоге пропускает.
- Модель, найденная для конкретного корабля, относится к нему, даже если общее
  правило классификатора решило бы иначе (YT-2400 найден как пиратский корсар).

Кораблей, для которых скачиваемых моделей нет нигде (Sketchfab и Objaverse),
`find_models.py` перечисляет в конце вывода.
